# 中国新能源车出海 · 金融保险战略 — 报告学习笔记

> 基于 Oliver Wyman 为 Fidelidade / 复星 做的 Phase 1 Final V2（2026年7月28日，181页）
> 本笔记目的：从零上手，读完能与人正常讨论这个项目。

---

## 0. 三句话记住全局

1. **市场是真的**：到2030年，中国电动车在欧洲对应的车险市场约 €50亿保费、汽车金融约 €490亿贷款余额；英国最大、德国次之、西班牙第三。
2. **打法是"3+1"**：复星有四条路，三条短中期做、一条长期做。核心思路——先从葡萄牙（自己的地盘）做试点，跑通后靠 MGA 复制到全欧。
3. **现实能吃到的（SAM）约 €8–22亿**，远小于 €50亿的 TAM，因为多数消费者自选保险公司，车企/经销商只能影响 20–30%。

## 1. 这个行业到底是什么生意

卖一台车实际被拆成三笔生意：

| | 卖什么 | 谁付钱 |
|---|---|---|
| 车本身 | 一台车 | 消费者 / 租赁公司 |
| 汽车金融 | 让你分期付得起 | 消费者付利息 |
| 汽车保险 | 出事有人赔 | 消费者付保费 |

**关键认知**：后两笔生意利润往往比卖车更稳定。传统车企（大众、宝马）都有自营金融公司（captive finance）。而且它反过来影响卖车——保险太贵、利率太高，消费者就不买了。

### 中国车企出海，为什么金融保险成了痛点

- **① 没历史数据 → 保险贵**：保险公司靠历史赔付定价，中国品牌是新面孔 → 保守定价。BYD访谈：EV保费比油车高 **30–40%**，主因电池更换成本。
- **② 没维修网络 → 赔付高**：缺认证维修厂、原厂件、技师 → 修得慢又贵 → 保险公司赔得多 → 保费更贵（恶性循环）。
- **③ 欧洲不是一个市场，是27个市场**：各国监管、条款、渠道都不同，车企要逐国谈，成本极高。

这三条 = 整个项目的商业机会来源。

## 2. 生态里有谁，钱怎么分（报告 P69）

消费者交的保费（行业叫 **GWP**，毛保费）在四个角色间分配：

![保费在生态各角色间的分配](图_保费分配.png)

| 角色 | 分成 | 干什么 |
|---|---|---|
| **承保方 carrier** | 75–85% | 真正的保险公司（Allianz、Fidelidade），承担赔付风险 |
| **联合中介** | 8–13% | 车企合资持有，为了从"拿返点"变"分利润" |
| **MGA 平台** | 4–8% | 有牌照的"保险外包运营商"，不担风险赚佣金 |
| **经销商** | 3–6% | 卖车时顺手卖保单 |

### 反直觉的关键点

承保方拿大头，看起来最赚 —— **但事实相反**。

- 欧洲车险"综合成本率"（**COR** = 赔款+费用÷保费）常年 100% 附近甚至以上：德国约104%、法国约101%、英国约104%。
- **COR > 100% = 承保是亏钱的**，靠投资收益弥补。
- 特斯拉在欧洲和 Qover 的合作目前赔付率 >100%，**主要在亏损**。

**隐含核心逻辑**：在欧洲车险里，当承保方不一定赚钱；赚钱的是中介层（旱涝保收的佣金）和**能真正把赔付降下来的能力**。

## 3. 术语速查

**金融侧**
- **GWP** — 毛保费收入，保险行业的"营业额"
- **Loss ratio 赔付率** — 赔出去的钱 ÷ 收到的保费
- **COR 综合成本率** — 赔付率 + 费用率；>100% = 承保亏损
- **Captive finance 自营金融** — 车企自己的金融公司
- **Floorplan financing 库存融资** — 借钱给经销商压库存
- **PCP / HP** — 英国两种分期。HP=普通分期（付完车归你）；PCP=低月供+尾款（尾款不付就还车）
- **残值 Residual Value (RV)** — 合同结束时车还值多少钱（租赁生意的生死线）
- **GAP 保险** — 车全损时，赔付额与欠款之间的差额

**保险侧**
- **MTPL** — 交强险（第三方责任险），欧洲各国法定必买
- **MOD** — 车损险，保自己的车
- **UBI** — 按驾驶行为定价的保险
- **嵌入式保险 embedded insurance** — 保险直接嵌在买车流程里
- **MGA** — Managing General Agent，有牌照代保险公司设计/定价/卖/理赔，但不担风险
- **TPA** — 第三方理赔/服务外包商

**渠道侧**
- **2C** — 直接卖给消费者
- **B2B2C** — 经销商卖给消费者（绝对主流，多数车企75–95%）
- **2B** — 卖给租赁公司、车队
- **NSC** — National Sales Company，车企各国销售公司（负责当地落地执行）

## 4. 残值：为什么整个行业都盯这一个数

租赁公司月租金公式（P75）：

```
月租 ≈（购车成本 − 预计残值）+ 资金成本 + 服务成本 + 保险成本 + 风险溢价 + 利润
```

- **残值估高** → 月租便宜好卖，但三年后车卖不上价，租赁公司亏
- **残值估低** → 月租太贵，卖不动

中国品牌的问题：**没人知道三年后它值多少钱**（品牌新、二手数据缺、电池健康度不透明）→ 租赁公司要么不接，要么按最保守算 → 报价没竞争力。

**结论**：中国车企要打进欧洲租赁渠道，光靠车便宜没用，必须解决"残值、可维修性、可保性、可转卖性"四个不确定性。**谁解决残值 = 谁打开占欧洲一半的B2B渠道。**

## 5. 三个市场口径：TAM / SAM（全篇最诚实的地方）

![TAM / SAM 市场口径漏斗](图_TAM_SAM漏斗.png)

```
TAM 总可服务市场  约 €50亿   ← 理论天花板
   ↓ （70–80%消费者自选保险，只有20–30%听车企/经销商）
SAM 战略可获取市场 €8–22亿   ← 复星四条战略现实能触达
   ↓
真正能拿下的份额  取决于执行，报告未给数
```

- **TAM**（Total Addressable Market）= €50亿，中国电动车在欧洲对应的全部车险保费
- **SAM**（Serviceable Addressable Market）= €8–22亿，复星"3+1"战略现实能够到的
- 中间大幅缩水的原因：**欧洲70–80%消费者自己上网/找代理选保险，只有20–30%听经销商/车企推荐**

> ⚠️ SAM 区间宽达2.75倍（8→22亿），说明顾问自己也没把握。

## 6. A部分 · 市场有多大

- 中国车企2025年海外销量约 **400万辆**，年增约 **30%**，欧洲占一半。
- **TAM（2030）**：欧洲车险 €50亿 GWP / 汽车金融 €490亿余额；拉美 €7亿 / €230亿。

### 分国家市场大小 vs 复星落地能力（P11，最有用的一页）

| 国家 | 2030车险TAM | Fidelidade牌照/分支 | COR |
|---|---|---|---|
| 英国 | €12亿 | ❌ 无 | 100% |
| 德国 | €7亿 | ❌（只有寿险） | 104% |
| 西班牙 | €4亿 | ✅ 有分支 | **94%** |
| 意大利 | €3亿 | ❌ | 99% |
| 法国 | €2亿 | ✅ 有分支 | 100% |
| 葡萄牙 | €1亿 | ✅ 核心市场 | — |
| 巴西 | 拉美最大 | ❌ | 80% |

**核心矛盾（错配）**：市场最大的（英/德）复星没落地能力；复星有能力的（葡/西）市场偏小。**整个战略就是为了解决这个错配** → 从葡萄牙试点、靠MGA向外扩。

**西班牙是亮点**：主要市场里唯一 COR<100%（94%，能赚钱），+ 有分支 + 监管更宽松 → 被点名为第二站。

## 7. B部分 · 怎么赢得车企

### 车企分三类（P12）
- **长期深耕型**：BYD、吉利、上汽、奇瑞 — 认真做欧洲，愿搭生态
- **抢量型**：零跑、长城、广汽 — 只求快速铺量冲销量
- **出行服务型（科技车企）**：小鹏、蔚来 — 死磕用户体验

### 关键组织洞察（P13）："总部签约 ≠ 落地成交"
战略合作是车企集团总部批的，但真正卖保险的是各国销售公司（NSC）。**就算和BYD总部签了大单，没有当地销售+售后支持也变不成实际保单。** → 这正是复星的机会点（提供落地执行能力）。

### 三类客户选承保方的逻辑不同（P8 / P117）
- **车企**：当地执行强、理赔好、价格有竞争力（但不要求最低价）
- **MGA**：给的佣金高、终端价格有吸引力
- **租赁/车队**：**价格第一**，因为保费直接吃掉它的利润

### 被低估的大机会：租赁/车队（B2B）
- 中国车企 80–90% 走经销商直销，几乎没做租赁/车队
- 但租赁/车队占欧洲新车市场 **50–60%**
- 没做的原因还是残值 → 谁解决残值谁打开这个渠道（= 战略3的由来）

## 8. C部分 · 复星的"3+1"战略（最终版灵魂）

> W1版完全没有，最终版新增的核心结论。

![复星 3+1 战略四条路径](图_3plus1战略.png)

### 短中期 · "3"

**战略1 · 核心市场承保方**（送分题 / no-brainer）
- 在自己强的地盘直接当保险公司：葡萄牙（现在）、西班牙（潜在）
- 角色：承保方 · 渠道 B2B2C · **SAM €1–5亿**
- 最容易，立刻能做，但市场小

**战略2 · 泛欧 MGA**（主引擎）
- 收购一个MGA平台，服务尚无独家保险伙伴的车企（奇瑞、上汽、广汽等）
- 角色：MGA平台 · 渠道 B2B2C · **SAM €4–9亿**
- 需并购，是把小市场撬成全欧大市场的杠杆

**战略3 · 车队/租赁生意**（钱最大但最难）
- 和车企、租赁公司三方合作，解决残值痛点，打开B2B渠道
- 角色：承保方 · 渠道 B2B · **SAM €4–11亿**
- 潜力最大，但最依赖能力搭建（售后网、二手车体系）

### 长期 · "+1"

**+1 · 与顶级车企合资（JV / 自保公司）**
- 前三条建立信任后，再深度绑定一家头部车企，锁定长期规模
- 实施复杂度最高，需前期合作先跑通

### 复星凭什么能做（right to win，P136）
- 葡萄牙有强执行力和品牌 → 支撑战略1
- 通过复星和中国车企关系近 → 支撑战略2、3
- **手握大中华再保险资源（中再、鼎睿再保险 Peak Re）→ 能给MGA和车队生意提供风险承接** → 别的欧洲玩家没有的独特筹码

### 落地路线（P137）
**葡萄牙做试验田**：先用承保方模式，把"经销商系统打通 + 秒级核保定价 + 售后生态（折扣配件、共建维修网、电池保障）"跑通，验证成功后复制到其他市场（承保方或MGA模式）。

### 对不同车企怎么接触（P139）
| 车企 | 打法 |
|---|---|
| BYD | 先在西班牙用战略1切入（已有bolttech，别硬抢）；长期看战略3 |
| 吉利/上汽 | 战略1建信任 → 战略2做规模（它们已在推车队） |
| 奇瑞 | 欧洲能力弱、对新方案兴趣大 → 战略2最优先 |
| 零跑/长城/广汽 | 等能力建好，主打战略2+3 |
| 小鹏/蔚来 | 小而创新，选择性合作未来出行保险 |

## 10. 报告仍存在的问题（可带去讨论 / 你的价值所在）

1. **TAM核心假设没变**：P10脚注仍假设中国品牌单车保费与其他品牌相同。中国车更便宜 → 仍偏高估。SAM区间宽（€8–22亿）也印证不确定。
2. **战略2依赖"买一个MGA"，但没说买谁、多少钱**（P136只写"需收购有区域覆盖和数字能力的MGA"）→ 战略支点是个空格，**必问**。
3. **承保盈利矛盾未解**：德国COR 104%、英国100%，报告自己把德国标为"负margin是carrier模式警示"。那战略1/3让Fidelidade承保怎么不亏？隐含答案"靠售后压赔付"，但压几个点没量化。
4. **中国险企后端模式被泼冷水（P112–114）**：平安-安联全球框架"目前无大规模落地"；东南亚"本地出单+高比例分回中国"再保险因赔付率一度>100%，中国险企已收紧、本地留存被要求提到20–30%。**东南亚经验不能直接复制欧洲**——别指望靠鼎睿简单兜底。
5. **英国隐藏门槛**：MGA和车队模式在英国落地更慢（独立牌照+fronting要求），而英国恰是最大市场（€12亿）。
